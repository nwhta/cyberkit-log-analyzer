# Log Analyzer — part of CyberKit

A fast tool for reading security and server logs, right in your browser.
Drop a log file and the format is detected automatically; the filters adapt to that format.
You get color-coded events with plain-language explanations, a "suspicious sources by IP" panel,
time range filtering, search, a Patterns view, data masking, CSV/PDF export, and a minimap of the whole log.
Lines that could not be parsed are never hidden: they are shown and counted as "Unparsed".

🌐 **Online version:** https://logs.cyberkit.me

**Privacy by design:** log files are analyzed entirely in the browser and are never uploaded.
The server only serves the pages.

**Built with AI:** most of the code was written with the help of AI. Every change is read, understood and tested by the developer.

## Supported formats

Windows Event Log (`.evtx` or XML export, including Sysmon and Microsoft Defender), Linux syslog
(auth.log / secure, messages, kern.log with UFW / iptables, mail.log, cron), Linux audit log (auditd),
systemd journal (`journalctl -o json`), Fail2ban, Nginx / Apache access log, Nginx error log,
Apache error log, IIS (W3C), JSON lines, Suricata `eve.json`, Zeek (TSV and JSON), AWS CloudTrail,
CEF, LEEF, Windows Firewall (`pfirewall.log`), pfSense / OPNsense `filterlog`, Cisco ASA / Firepower,
FortiGate, Palo Alto (PAN-OS CSV), AWS VPC Flow Logs, AWS ALB access logs, Snort / Suricata `fast.log`,
Windows DNS Server debug log, BIND query log, dnsmasq / Pi-hole, OpenVPN, PostgreSQL, MySQL / MariaDB,
Microsoft Entra ID sign-in logs, Microsoft 365 unified audit log, Azure Activity Log,
Google Cloud audit logs, Kubernetes audit log, Wazuh / OSSEC alerts.

The `.evtx` reader (`src/evtx.ts`) decodes the binary Windows event log format
(chunks, BinXML templates and substitutions) in the browser.

## Project structure

```
main.py            small FastAPI server: pages, static files, security headers
src/               TypeScript sources (edit these)
  parserTypes.ts     contract every log parser follows
  parserRegistry.ts  list of parsers + automatic format detection
  *Parser.ts         one file per log format
scriptsJS/         compiled JavaScript (generated by tsc)
templates/         HTML pages
styles/            CSS
static/demo/       demo logs (synthetic data, no real systems)
tools/             scripts that generate the demo logs
```
