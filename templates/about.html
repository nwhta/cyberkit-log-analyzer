About Log Analyzer

A tool for reading security and server logs. Drop a file, and it recognizes the format by itself: Windows (.evtx), Linux, firewalls, DNS, VPN, databases, web servers, IDS and cloud logs.

Built with AI. AI helps write the code faster. Every change is read, understood and tested by the developer.

Your logs stay with you

Everything runs in your browser. Nothing is uploaded, and you can check it with F12 → Network.

This is the self-hosted version

Log Analyzer is the first tool of the CyberKit platform. The online version has extra features and gets updates first.
